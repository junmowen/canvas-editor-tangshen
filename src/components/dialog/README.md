# Dialog 目录说明

`components/dialog/` 存放轻量弹窗组件。

## 位置说明

- 所属层级：共享组件层 / 弹窗
- 上游调用：demo 菜单和核心辅助交互
- 下游依赖：`dialog.css`、浏览器 DOM

## 文件说明

| 文件 | 职责 |
| --- | --- |
| `Dialog.ts` | 根据配置渲染表单弹窗并回传确认结果。 |
| `dialog.css` | 弹窗遮罩、容器、按钮和表单样式。 |

## 函数说明

| 文件 | 函数 / 方法 | 作用 | 调用地方 |
| --- | --- | --- | --- |
| `Dialog.ts` | `Dialog` | 创建、打开、关闭弹窗并收集输入值。 | demo 插入菜单、设置菜单 |
