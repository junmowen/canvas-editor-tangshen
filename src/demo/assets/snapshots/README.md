# Demo Snapshots 目录说明

`demo/assets/snapshots/` 存放历史版本演示截图。

## 位置说明

- 所属层级：demo 资源层 / 截图
- 上游调用：文档或展示页面
- 下游依赖：无

## 文件说明

| 文件 | 职责 |
| --- | --- |
| `main_v*.png` | 不同版本 demo 主界面截图。 |

## 函数说明

| 文件 | 函数 / 方法 | 作用 | 调用地方 |
| --- | --- | --- | --- |
| `main_v*.png` | 无运行时函数 | 保存版本截图资源。 | 文档或展示页 |
