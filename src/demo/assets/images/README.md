# Demo Images 目录说明

`demo/assets/images/` 存放 demo 工具栏和菜单使用的 SVG 图标。

## 位置说明

- 所属层级：demo 资源层 / 图标
- 上游调用：demo 样式和菜单 DOM
- 下游依赖：无

## 文件说明

| 文件 | 职责 |
| --- | --- |
| `*.svg` | 工具栏、插入菜单、格式菜单和页面设置图标。 |

## 函数说明

| 文件 | 函数 / 方法 | 作用 | 调用地方 |
| --- | --- | --- | --- |
| `*.svg` | 无运行时函数 | 作为静态图标资源被引用。 | demo UI |
