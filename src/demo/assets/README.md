# Demo Assets 目录说明

`demo/assets/` 存放 demo 使用的图标和版本截图。

## 位置说明

- 所属层级：demo 资源层
- 上游调用：demo HTML / CSS / 菜单
- 下游依赖：SVG 和 PNG 静态文件

## 文件说明

| 目录 | 职责 |
| --- | --- |
| `images/` | demo 工具栏和菜单图标。 |
| `snapshots/` | demo 版本截图。 |

## 函数说明

| 目录 | 函数 / 方法 | 作用 | 调用地方 |
| --- | --- | --- | --- |
| `images/` | 无运行时函数 | 提供 demo 菜单 SVG 图标。 | demo 页面 |
| `snapshots/` | 无运行时函数 | 保存演示截图资源。 | 文档或展示页 |
