# Demo Styles 目录说明

`demo/styles/` 存放 demo 页面样式。

## 位置说明

- 所属层级：demo 样式层
- 上游调用：demo HTML / main 入口
- 下游依赖：demo DOM class

## 文件说明

| 文件 | 职责 |
| --- | --- |
| `style.css` | demo 主样式入口。 |
| `style.base.css` | 基础布局和通用样式。 |
| `style.insert-menu.css` | 插入菜单样式。 |
| `style.layout-panel.css` | 布局面板样式。 |
| `style.review-footer.css` | 修订 / 评论页脚样式。 |

## 函数说明

| 文件 | 函数 / 方法 | 作用 | 调用地方 |
| --- | --- | --- | --- |
| `*.css` | 无运行时函数 | 提供 demo 页面视觉样式。 | demo 页面 |
