# Badge 模块

`badge/` 承接文档签章和区域签章业务运行对象。

## 子目录说明

| 目录 | 职责 |
| --- | --- |
| `runtime/` | 签章配置缓存、可绘制签章坐标解析和签章图片绘制 |

## 维护规则

- 签章运行对象留在本模块，不再放回 `draw/frame/Badge.ts`。
- 区域位置信息通过 area 模块实例读取，不在本模块重复计算区域布局。

## 位置说明

- 所属层级：业务模块层 / 签章
- 上游调用：page setup render、draw component registry
- 下游依赖：`runtime/`、area 模块

## 文件说明

| 目录 | 职责 |
| --- | --- |
| `runtime/` | 签章配置缓存、坐标解析和图片绘制。 |

## 函数说明

| 目录 | 主要入口 | 作用 | 调用地方 |
| --- | --- | --- | --- |
