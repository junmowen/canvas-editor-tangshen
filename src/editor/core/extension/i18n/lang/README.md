# I18n Lang 目录说明

`i18n/lang/` 存放内置语言资源。

## 位置说明

- 所属层级：扩展层 / i18n 语言包
- 上游调用：`I18n.ts`
- 下游依赖：菜单、控件和模块文案 key

## 文件说明

| 文件 | 职责 |
| --- | --- |
| `*.ts` | 按 locale 维护内置语言文案。 |

## 函数说明

| 文件 | 函数 / 方法 | 作用 | 调用地方 |
| --- | --- | --- | --- |
| `*.ts` | 默认语言对象导出 | 提供指定 locale 的文案映射。 | `I18n.ts`、`Register.langMap()` |
