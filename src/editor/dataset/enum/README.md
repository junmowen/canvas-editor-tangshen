# Dataset Enum 目录说明

`dataset/enum/` 存放编辑器枚举定义。

## 位置说明

- 所属层级：编辑器数据定义层 / 枚举
- 上游调用：core、interface、utils、外部导出
- 下游依赖：无运行时状态

## 文件说明

| 文件 / 目录 | 职责 |
| --- | --- |
| `*.ts` | 编辑器模式、元素类型、事件、行、文本等枚举。 |
| `table/` | 表格相关枚举。 |

## 函数说明

| 文件 / 目录 | 函数 / 方法 | 作用 | 调用地方 |
| --- | --- | --- | --- |
| `*.ts` | enum 导出 | 提供稳定枚举值，无业务函数。 | core、interface、外部导出 |
| `table/` | table enum 导出 | 提供表格工具、边框、命中等枚举。 | table 模块 |
