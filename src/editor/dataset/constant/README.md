# Dataset Constant 目录说明

`dataset/constant/` 存放编辑器静态常量和默认配置。

## 位置说明

- 所属层级：编辑器数据定义层 / 常量
- 上游调用：core、utils、interface、外部导出
- 下游依赖：无运行时状态

## 文件说明

| 文件 | 职责 |
| --- | --- |
| `*.ts` | 按业务域导出默认配置、尺寸、正则、菜单和快捷键常量。 |

## 函数说明

| 文件 | 函数 / 方法 | 作用 | 调用地方 |
| --- | --- | --- | --- |
| `*.ts` | 常量导出 | 提供运行时默认值和静态配置，无业务函数。 | core、utils、外部导出 |
