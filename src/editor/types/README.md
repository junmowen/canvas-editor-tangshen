# Types 目录索引

`src/editor/types/` 存放补充类型声明。

## 维护规则

- 仅放 TypeScript 无法从源码直接推导、但构建或使用方需要的声明。
- 对外业务接口优先放在 `src/editor/interface/`。

## 位置说明

- 所属层级：编辑器补充类型层
- 上游调用：TypeScript 编译
- 下游依赖：无运行时依赖

## 文件说明

| 文件 | 职责 |
| --- | --- |
| `index.d.ts` | 补充第三方或全局类型声明。 |

## 函数说明

| 文件 | 函数 / 方法 | 作用 | 调用地方 |
| --- | --- | --- | --- |
| `index.d.ts` | 类型声明 | 提供编译期类型补充，无运行时函数。 | TypeScript 编译 |
