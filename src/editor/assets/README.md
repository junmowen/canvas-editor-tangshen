# Assets 目录索引

`src/editor/assets/` 存放编辑器核心运行时需要的样式和图标资源。

| 目录 | 职责 |
| --- | --- |
| `css/` | 编辑器核心样式、右键菜单和控件相关样式 |
| `images/` | 编辑器核心图标和上下文菜单资源 |

## 维护规则

- demo 专用资源放入 `src/demo/assets/`，不要放进这里。
- 核心右键菜单、预览器、表格菜单等运行时资源保留在这里。

## 位置说明

- 所属层级：编辑器核心资源层
- 上游调用：`src/editor/index.ts`、runtime DOM 组件、菜单和浮层
- 下游依赖：CSS、SVG 图片资源

## 文件说明

| 目录 | 职责 |
| --- | --- |
| `css/` | 编辑器核心组件、菜单、控件、表格等样式。 |
| `images/` | 编辑器运行时菜单、表格、图片工具使用的 SVG 图标。 |

## 函数说明

| 目录 | 函数 / 方法 | 作用 | 调用地方 |
| --- | --- | --- | --- |
| `css/` | 无运行时函数 | 提供编辑器 DOM 和浮层样式。 | `src/editor/index.ts`、runtime DOM |
| `images/` | 无运行时函数 | 提供菜单和工具栏 SVG 图标资源。 | contextmenu、previewer、table tool |
