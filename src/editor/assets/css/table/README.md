# Table CSS 目录说明

`assets/css/table/` 存放表格工具条样式。

## 位置说明

- 所属层级：编辑器资源层 / table 样式
- 上游调用：`assets/css/index.css`
- 下游依赖：table tool DOM class

## 文件说明

| 文件 | 职责 |
| --- | --- |
| `table.css` | 表格工具条、菜单和操作按钮样式。 |

## 函数说明

| 文件 | 函数 / 方法 | 作用 | 调用地方 |
| --- | --- | --- | --- |
| `table.css` | 无运行时函数 | 提供表格工具条视觉样式。 | table particle / tool |
