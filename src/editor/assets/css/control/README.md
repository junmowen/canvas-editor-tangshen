# Control CSS 目录说明

`assets/css/control/` 存放控件样式。

## 位置说明

- 所属层级：编辑器资源层 / control 样式
- 上游调用：`assets/css/index.css`
- 下游依赖：control DOM class

## 文件说明

| 文件 | 职责 |
| --- | --- |
| `select.css` | select 控件弹层和选项样式。 |

## 函数说明

| 文件 | 函数 / 方法 | 作用 | 调用地方 |
| --- | --- | --- | --- |
| `select.css` | 无运行时函数 | 提供 select 控件视觉样式。 | control select runtime |
