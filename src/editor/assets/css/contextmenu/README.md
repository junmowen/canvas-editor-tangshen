# Contextmenu CSS 目录说明

`assets/css/contextmenu/` 存放右键菜单样式。

## 位置说明

- 所属层级：编辑器资源层 / contextmenu 样式
- 上游调用：`assets/css/index.css`
- 下游依赖：contextmenu DOM class

## 文件说明

| 文件 | 职责 |
| --- | --- |
| `contextmenu.css` | 菜单容器、菜单项、子菜单样式。 |

## 函数说明

| 文件 | 函数 / 方法 | 作用 | 调用地方 |
| --- | --- | --- | --- |
| `contextmenu.css` | 无运行时函数 | 提供右键菜单视觉样式。 | `runtime/contextmenu` |
