# Zone CSS 目录说明

`assets/css/zone/` 存放编辑区域提示样式。

## 位置说明

- 所属层级：编辑器资源层 / zone 样式
- 上游调用：`assets/css/index.css`
- 下游依赖：zone tip DOM class

## 文件说明

| 文件 | 职责 |
| --- | --- |
| `zone.css` | 页眉、正文、页脚区域提示样式。 |

## 函数说明

| 文件 | 函数 / 方法 | 作用 | 调用地方 |
| --- | --- | --- | --- |
| `zone.css` | 无运行时函数 | 提供区域提示视觉样式。 | `runtime/zone` |
