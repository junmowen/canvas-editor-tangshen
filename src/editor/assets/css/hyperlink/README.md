# Hyperlink CSS 目录说明

`assets/css/hyperlink/` 存放超链接浮层样式。

## 位置说明

- 所属层级：编辑器资源层 / hyperlink 样式
- 上游调用：`assets/css/index.css`
- 下游依赖：hyperlink DOM class

## 文件说明

| 文件 | 职责 |
| --- | --- |
| `hyperlink.css` | 超链接弹层和操作样式。 |

## 函数说明

| 文件 | 函数 / 方法 | 作用 | 调用地方 |
| --- | --- | --- | --- |
| `hyperlink.css` | 无运行时函数 | 提供超链接浮层视觉样式。 | inline hyperlink particle |
