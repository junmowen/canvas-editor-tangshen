# Date CSS 目录说明

`assets/css/date/` 存放日期控件样式。

## 位置说明

- 所属层级：编辑器资源层 / date 样式
- 上游调用：`assets/css/index.css`
- 下游依赖：date picker DOM class

## 文件说明

| 文件 | 职责 |
| --- | --- |
| `datePicker.css` | 日期选择器弹层样式。 |

## 函数说明

| 文件 | 函数 / 方法 | 作用 | 调用地方 |
| --- | --- | --- | --- |
| `datePicker.css` | 无运行时函数 | 提供日期选择器视觉样式。 | date control runtime |
