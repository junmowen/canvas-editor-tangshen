# Resizer CSS 目录说明

`assets/css/resizer/` 存放缩放控制点样式。

## 位置说明

- 所属层级：编辑器资源层 / resizer 样式
- 上游调用：`assets/css/index.css`
- 下游依赖：resizer DOM class

## 文件说明

| 文件 | 职责 |
| --- | --- |
| `resizer.css` | 图片或对象 resize 控制点样式。 |

## 函数说明

| 文件 | 函数 / 方法 | 作用 | 调用地方 |
| --- | --- | --- | --- |
| `resizer.css` | 无运行时函数 | 提供 resize 控制点视觉样式。 | image previewer |
