# Canvas Editor Open Issues 单人推进初始值

## 1. 目的

这份文档用于给 [upstream-open-issues-solo-full-table.md](./upstream-open-issues-solo-full-table.md) 提供一版“推荐初始值”。

注意：

1. 这里不会替你最终判断“是否命中业务”
2. 这里只给出单人开发时最省力的默认起手方式
3. 你后面只需要按自己的业务把少量条目改掉

推荐思路：

1. bug、核心主线、明显会影响现有编辑链的项，默认 `未验证`
2. 纯 roadmap、明显超大功能、与你大概率无关的能力，默认 `暂不处理`
3. 不确定但实现面较小的功能诉求，默认 `未验证`

## 3. 推荐你第一天只做这些

如果你想最低成本起步，先只处理下面这些：

1. `#41`
2. `#94`
3. `#813`
4. `#1163`
5. `#1399`
6. `#446`
7. `#837`

原因：

1. 这批要么是核心主线
2. 要么是高概率命中真实使用的 bug / 性能问题
3. 先验证它们，收益最大

---

## 4. 推荐你怎么回填总表

你可以直接参考这份文档，把总表里的默认值先改成：

1. 推荐是否命中业务为 `否` 的，先改成 `否`
2. 推荐状态为 `暂不处理` 的，先改成 `暂不处理`
3. 剩下的统一保留 `未验证`

这样你会立刻把 50 条压缩成一小批真正要处理的条目。
