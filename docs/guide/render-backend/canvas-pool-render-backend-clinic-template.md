# 真实业务模板压测

### 14.4 第三阶段：真实业务模板压测

目标：从纯文本和构造表格用例升级到真实门诊病历模板，验证当前算法在复杂页面上的表现。

当前进度：

1. 已新增 `cypress/e2e/performance/clinic-template-baseline.cy.ts`，作为第三阶段真实业务模板压测入口。
2. 当前仓库没有独立的真实门诊模板 fixture，因此第一版先在 Cypress 内构造门诊病历模板，覆盖页眉、页脚、页码、水印、跨页表格、控件、图片、长段落和分页符。
3. 已建立 20 / 100 / 500 页三档 `setValue` 基线，断言页面数、页眉页脚、表格、控件、图片、中间页行数据和 position 数据完整。
4. 已增加 100 页模板的前部输入、中段输入、表格单元格输入回归，要求普通正文输入不触发整篇 layout，dirty range 不漏页，表格补录能正确写入目标单元格。
5. 已增加 100 页模板的大粘贴 + 导出图片回归，验证后台事务完成、最终 layout 收敛、中间页完整、导出图片包含真实病历像素。
6. 已增加 500 页模板的渲染缓存 / 内存统计基线，验证额外可视页渲染调度、backend miss 和总内存估算处于可控范围。
7. 首轮运行已暴露并修正测试层校准问题：表格快照统计应读取 `tableSnapshot.build.buildCount`，示例页面的 `rangeStyleChange` DOM 监听在 headless 下可能读到空节点，500 页滚动不能假设任意页 canvas 常驻挂载。
8. 压测模板的水印和页码改为直接写入 editor options 后再 `setValue`，避免测试准备阶段额外触发一次无意义渲染；500 页缓存基线改为验证渲染调度、backend miss、内存和文档完整性，不再绑定具体页 canvas 是否已挂载到 DOM。
9. 中段正文输入锚点已收紧为普通正文字符，避开标题结构和控件内部 value；当前 `clinic-template-baseline.cy.ts` 4 个真实模板压测用例通过。

模板要求：

1. 至少包含水印、页眉页脚、页码、跨页表格、控件、图片、长段落和表格前后同页正文。
2. 至少覆盖 20 页、100 页、500 页三档数据量。
3. 同一模板需要提供纯查看、前部输入、中部输入、表格输入、大粘贴、撤销重做、滚动检查和导出截图路径。

验收标准：

1. 前部普通输入不触发整篇 layout，且可见输入延迟保持在当前 1000 页性能基线范围内。
2. 表格输入不出现旧边框残留、重复 fragment、文字越过 td bounds 或光标跳回第一页。
3. 大粘贴首帧不冻结，后台完成后中间页和尾页内容完整。
4. 连续粘贴、撤销、重做、滚动后，bitmap cache、layout cache、active surface 数量能回落。
